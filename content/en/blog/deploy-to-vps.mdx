# Deploy Indigo to a $4 VPS with Docker and Caddy

This guide walks through the exact setup running [demo.indigo-fw.dev](https://demo.indigo-fw.dev) — a Hetzner CX22, Docker Compose, Caddy, Cloudflare, and GitHub Actions. Total cost: about €4/month.

<Callout type="info">
You'll need a domain, a Cloudflare account (free), and a Hetzner account. The whole setup takes 20-30 minutes.
</Callout>

## 1. Provision the VPS

Create a CX22 on Hetzner Cloud (2 vCPU, 4 GB RAM, Ubuntu 22.04). Add your SSH key during creation.

Once it's up, SSH in and run the bootstrap:

```bash
apt update && apt install -y docker.io docker-compose-plugin git
useradd -m -s /bin/bash deploy
usermod -aG docker deploy
mkdir -p /opt/indigo
```

## 2. Configure Cloudflare

Point your domain's nameservers to Cloudflare. Add an `A` record pointing to your VPS IP, proxied (orange cloud). Set SSL/TLS to **Full (Strict)**.

This gives you free DDoS protection, WAF, and edge caching — before a single request hits your server.

## 3. Configure Caddy

Create `/opt/indigo/Caddyfile`:

```caddy
your-domain.com {
  reverse_proxy app:3000
}
```

Caddy handles HTTPS automatically via Let's Encrypt. No cert management needed.

## 4. Create docker-compose.prod.yml

```yaml
services:
  app:
    image: ghcr.io/your-org/your-repo:latest
    restart: unless-stopped
    env_file: .env
    depends_on: [postgres, redis]

  caddy:
    image: caddy:2-alpine
    ports: ["80:80", "443:443"]
    volumes:
      - ./Caddyfile:/etc/caddy/Caddyfile
      - caddy_data:/data
    depends_on: [app]

  postgres:
    image: postgres:16-alpine
    environment:
      POSTGRES_DB: indigo
      POSTGRES_USER: indigo
      POSTGRES_PASSWORD: ${POSTGRES_PASSWORD}
    volumes: [pg_data:/var/lib/postgresql/data]

  redis:
    image: redis:7-alpine
    volumes: [redis_data:/data]

volumes:
  caddy_data:
  pg_data:
  redis_data:
```

## 5. Set Up GitHub Actions

Add these secrets to your GitHub repo:
- `DEMO_HOST` — your VPS IP
- `DEPLOY_SSH_KEY` — private SSH key for the `deploy` user

The starter includes `.github/workflows/deploy-demo.yml`. Push to `main` and it automatically builds, pushes to GHCR, and deploys.

## 6. First Deploy

```bash
# On your VPS, as deploy user
cd /opt/indigo
docker compose -f docker-compose.prod.yml pull
docker compose -f docker-compose.prod.yml up -d
docker compose -f docker-compose.prod.yml exec app bun run init
```

`bun run init` runs migrations, creates your superadmin, and seeds content. That's it — your app is live.

<Callout type="warning">
Make sure your `.env` on the VPS has `NODE_ENV=production` and a strong `BETTER_AUTH_SECRET`. Use `openssl rand -hex 32` to generate secrets.
</Callout>

## What You Get

- Zero-downtime deploys (pull → up -d swaps containers)
- Automatic HTTPS with Caddy
- Cloudflare WAF and rate limiting in front
- Full CI/CD from a git push
- ~3 minute deploy times

Total monthly cost: **€3.79** for the VPS, everything else is free.
